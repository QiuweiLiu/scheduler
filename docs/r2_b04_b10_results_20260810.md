## 核心结论(validation-screening 口径;最终候选待 finalist/final holdout)

1. **序列模型在 validation 上大幅领先(点估计)**:B05 GRU / B06 LSTM / B07 causal TF 的 joint 达 0.878-0.880,高于 XGB(0.8501)约 +2.8~3.0pp、高于静态 MLP 约 +2.9pp。该提升在 3 seeds 上方向一致,但 paired bootstrap/CI 未完成(见待办),正式表述为"validation 点估计",不宣称统计显著。
2. **B10(0.8768)高于 B09(0.8565)约 +2.0pp(点估计)**:支持"残差增益与序列建模相关"的假设;zero/shuffle 消融(N1)未完成,不宣称因果证明。
3. **静态路线天花板 ≈0.85(validation)**:B03 MLP / B04 FT / B08 meta 均未超 XGB 0.1pp 以上。
4. **家族与角色双头均受益(validation)**:序列模型 family Top1 0.79-0.81(超 XGB 0.761 约 +3~5pp)、role Top1 0.93-0.94(超 XGB 0.920 约 +1.4pp)。
5. **生产候选(待 finalist 确认)**:B05 GRU(主)+ B10 GRU residual(备);三者序列模型(B05/B06/B07)差异 0.2pp 内,需 paired bootstrap 定夺。
