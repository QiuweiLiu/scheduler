### 结论(NN 增强全部收尾)

1. **五种增强手段均未超过 XGBoost 级联**(整体口径:join 0.8428 vs 0.8493,差距 0.65pp);单级口径(next 语义)NN 与 XGB(0.7954)同量级,GRU 0.8096 反超,但特征为近似复刻,差距在 ±1pp 噪声内,不作压倒性结论。
2. **① OOF stacking 是最接近的 NN 方案**(join 0.8428,差 0.65pp)——若未来需要 NN,优先这个。
3. **角色正则无效**(0.8388 是基准):角色 NN 短板不是过拟合,是任务性质。
4. **④ FT-Transformer 是 NN 结构里整体最高的**(0.8296),支持"交互建模有助 NN",但不足以翻盘。
5. **最终生产配置(冻结,行为侧)**:XGBoost 级联(角色 0.9151 → 动作族 0.8950,最优特征集),整体 join 0.8493 / 执行者路由 0.9520。NN 探索结束,不再投入。
6. **BiLSTM/GRU 补测(用户追问遗漏,2026-08-07)**:此前 BiLSTM 的优势(0.8559)只在"当前行语义 + 从属层特征"下成立;在 next 语义 + 最优特征集下补测,单级 0.8078 / 0.8096;同期补跑的 next 语义 XGB 锚点为 0.7954(文档旧引 0.8950 为当前行语义,已修正)——序列模型与树在 next 语义下同量级,GRU 略高;整体 join 0.8428 / 0.8447 仍低于 XGBoost(0.8493)。序列模型优势不跨语义迁移,但"大幅落后"的旧结论撤销。
8. **全 NN 补测(用户追问,2026-08-07,产物 nn_both_gru_20260807.json)**:角色与动作族**都用 NN**(GRU+GRU)整体 join = **0.8033**(角色 GRU 0.8737 / 动作族 GRU 0.8060)。结论:**角色头是 NN 最大短板**(GRU 0.8737 vs XGB 0.9322,差 5.9pp),动作族头 NN 反而略超(0.8060 vs 0.7954);全 NN 仍比 XGB 级联低 4.6pp;最优组合 = XGB 角色 + 任意动作族头(XGB 或 GRU,差 0.5pp 内)。
