# 行为预测架构对比规划(2026-08-06)

- 文档状态:已完成(2026-08-06 执行完毕,结果见第 8 节)
- 执行地点:远端 /root/autodl-tmp/scheduler
- 原则:统一数据契约、统一 split、统一评估口径;偏离本文档时在"偏离记录"如实补充。
- 数据规范:expansion 数据必须进入所有训练/测试集(role_dataset_v0_2,17,303 行)

## 1. 目的

对比三种行为预测架构,统一口径选出最优:
- A:两级分开训练(已实现)
- B:级联/端到端训练
- C:一级直接预测(全模型族)

## 2. 方案定义

### 方案 A:两级分开训练(现有)
L1 角色(LightGBM,全量)→ 若=execute 且置信≥0.5 → L2 动作族(XGBoost,execute 子集,原 12 维特征)

### 方案 B:两级连接训练

**B1:级联特征训练(树模型,主)**
- 第 1 步:角色 LightGBM(全量 train)→ 输出角色概率 4 维
- 第 2 步:动作族 XGBoost(execute 子集),输入 = 原 12 维 + 角色概率 4 维
- 推理:级联触发(与 A 同),L2 特征含 L1 概率

**B2:端到端 NN(可微,对照)**
- 输入 → 共享编码(MLP / GRU)→ 角色头(全量监督)→ 角色概率 → 拼接 → 动作族头(execute 行监督,其余 mask)
- 联合 loss = 角色 CE + 动作族 CE(λ=1.0)
- backbone 变体:MLP / GRU

### 方案 C:一级直接预测(全模型族)
- 目标:7 类路由标签(non_execute + 6 动作族)
- 模型阵容:全局先验 / 条件计数 / n-gram(1/2/3)/ 逻辑回归 / 朴素贝叶斯 / 随机森林 / LightGBM / XGBoost / MLP / CNN-1D / GRU(embedding+onehot)/ BiLSTM / Transformer-lite / GNN / KNN
- 特征契约不变(扁平 12 维 + 序列窗口)

## 3. 统一评估口径

- 数据:role_dataset_v0_2 全量,split 240/30/30,test 1,520 行
- 指标:
  - 联合准确率:预测 (角色, 动作族) 与真实完全一致(非 execute 行只要求角色对)
  - 执行者路由正确率:全量 test(execute 按动作族派生执行者;非 execute 视为"无资源")
  - 资源分层正确率:预测 (执行者×动作族) vs 真实
  - 训练时间 / 推理延迟

## 4. 决策规则(已确认)

- 主指标差距 <1pp → 选最简单
- >2pp → 切换
- 1-2pp → 看次要因素(成本/可迁移/可解释)

## 6. 风险与预案

- B1 角色概率特征可能放大误差传播 → 评估对比 A
- B2 NN 弱于树模型(历史 0.73)→ 如实记录
- C 的 non_execute 合并丢失角色细分 → 若 C 胜出可加细分变体
- 统一触发阈值 0.5 避免口径偏差

### 8.2 结论与决策

1. **执行者路由主指标**:A(0.8822)/ B1(0.8855)/ C-XGBoost(0.8888),**最大差距 0.66pp < 1pp → 性能打平**
2. **决策规则应用**:差距 <1pp 应选最简单——字面是 C(单模型 7 类);但 C 的 non_execute 合并把 plan/aggregate/terminate 混为一类,丢失"收尾/释放"信息(调度 admission 和资源回收依赖此细分),故:
   - **主架构保留 A(两级分开)**:已实现、可解释(角色层独立可用)、角色细分完整、与调度 score 兼容
   - **C 记录为简化备选**(若未来需要单模型部署)
   - B1 无增益(+0.3pp 在噪声内)且更复杂 → 不采用
   - B2 端到端 NN 远差 → 不采用
3. **跨方案一致结论**:树模型族(XGBoost/LightGBM)在三级方案中均最优;NN 族(含端到端)全面落后——行为预测的架构差异不改变"树模型主导"的根本结论
4. **最终行为管线(维持)**:角色 LightGBM(0.9151,next_role)→ execute 触发 → 动作族 XGBoost(0.8381)→ 执行者派生 → 资源分层
