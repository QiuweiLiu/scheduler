# EXP-20261010_prefetch_value_methods_v1 — 预取模块:高预算 Rollout 蒸馏(B0–B5)

**状态:** 设计冻结(运行前) · 2026-10-10(替代此前同文件初稿;初稿从未运行)
**动机:** 固定 F0 排序、GPU 环境、驱逐规则、冻结 H5 预测器,**只优化预取模块**;
验证能否用高预算 Rollout 学出**低成本、高收益**的未来信息消费策略。

## 1. 五个对照臂(+参照)

| 臂 | 预取决策 | 说明 |
|---|---|---|
| 参照 | — | `sameshape_h5_p95`(F0,无动作;仅作上下文) |
| **① B0** 无预取 | 不预取,同驱逐 | 复用 `pdrs_evict`(同一价值表) |
| **② B1** 原主线 | 最大未来需求 U(m) | `pdrs_resident`(冻结) |
| **③ B2** 方法 A | **离线高预算 Rollout 蒸馏的轻量线性价值函数**,在线算分 | `pdrs_resident_da`(β 来自冻结产物) |
| **④ B3** 方法 B | 在线 Top-3(含不预取)= 无预取 + 蒸馏分前 2 目标;各 8 个**共同**场景短程 Rollout | `pdrs_resident_rollout` |
| **⑤ B5** 高预算参照 | 在线对**所有可行(模型,卡)动作**做 N* 场景 Rollout(离线同协议) | `pdrs_resident_hb` |

## 2. 开发集流水线(先做,冻结全部参数)

1. **状态采样**:dev 集主线轨迹(`pdrs_resident_probe`,与 B1 同决策),只在**存在合法预取候选**的时刻
   快照(≤6/集);快照=前沿项(节点/当前模型/预测剩余/内存)+ 设备状态(容量/驻留/忙闲)+ 全部可行
   候选动作(含实测干扰值)。
2. **高预算标签**(对每个采样状态)**:不预取 + 全部可行(模型,卡)动作;256 个**共同**抽样场景
   (种子 11,独立边际采样,详见披露);固定后续调度(当前任务最短优先、串行加载、轻量驱逐);
   收益 Δ=cost(不预取)−cost(动作),记录前缀 8/16/32/64/128/256 的收敛。**不读任何未揭示真值。**
3. **场景数收敛**:逐状态 argmax 选择与 N=256 的一致率 ≥90% 的最小 N 记为 **N*(冻结)**。
4. **价值函数拟合**:可解释线性模型,特征冻结为 10 维:`benefit_ms(时间截断期望节省)、uncapped_ms、
   u1_ms、demand_mass、first_need_ms、load_ms、memory_mb、mem_pressure、interference_ms、截距`;
   按 episode 划 train/val(70/30),报告 R² 与 val 动作一致率;β 与 N* 写入 `distilled_benefit_v1.json`。
5. **小规模验证**:dev 若干集跑五臂,检查零失败与时耗;然后冻结。

## 4. 判据(回答三问,冻结)

1. **B1 vs B0**:预取机制本身价值;若 B1 显著优于 B0 而 B2/B5 又显著优于 B1 →
   现行 U(m) 预取决策**浪费了未来信息**;
2. **B5 vs B1**:高预算 Rollout 提供的**额外可得收益**上界(在有限候选+采样条件下);
3. **B2/B3 vs B5**:低计算量方法能否**保留**高预算收益;并比较净收益(含在线开销)。
- 非显著不作等效结论;**⑤只能称"有限候选与采样条件下的近似最优参照",不宣全局最优**。

## 5. 场景与 Rollout 的近似(披露,冻结)

- 场景生成:**各节点链长 ~ 自身长度分布、逐步模型 ~ 该步边际、节点/步独立、时长=预测均值、
  不含未来到达**——逐步边际≠真实联合分布,这是本设计的核心近似;
- 短程仿真:只含前沿项+采样步;派发=当前任务最短优先;加载串行(忙设备加载乐观视为可重叠);
  驱逐=场景内后续无人使用优先;成本=各任务完成时间之和(对齐平均完成时间口径)。
- 所有参数(N*、β、种子、特征)在 dev 冻结后不再改动。

## 6. 开发阶段记录与冻结参数(确认运行前写入)

- **N\*(场景数)=256**:收敛口径下 8/16/32/64/128 的 argmax 一致率为
  0.704/0.767/0.762/0.812/**0.887(<0.90)**,故按判据冻结 **256**(dev,240 状态/649 动作行)。
- **β(蒸馏)**:标准化+岭回归(ridge=1e-3),train R²=0.110、**val R²=−1.442、val 动作一致率 0.417**
  ——拟合很弱,如实冻结;这不改变其作为"方法 A 主力实现"的地位,但预置了对 Q3 的悲观预期。
- **标签可信度(dev 检验)**:换种子重算 256 场景标签,**两种子相关 r=0.996、同号率 95.2%、
  平均偏差/幅度=0.08** → 标签非采样噪声;同时线性特征(含扩展 GPU 状态特征)不可预测 →
  "低计算量价值函数保留高预算收益"的难度来自**特征-机制鸿沟**,不是噪声。
- **B3 候选短名单** = U(m) 前二(不是蒸馏分排序——失效排名器不应作预筛),设备=最优可容纳卡。
- **dev 五臂验证(30 集,欠功效)**:完成收益 vs B0:B1 **+647** / B2 +352 / B3 **−556** / B5 +593;
  净收益(扣 CPU):B1 +647、B2 −220、B3 −3971、**B5 −48557**(CPU **49.1 s/集**)。
  B5−B3 mean −1149.5 [−2353,−86]。
- **评估计划(冻结)**:头条五臂+参照配对比较用 **confirm 前 100 集**(B5 按 ~49s/集,100 集 ≈ 82 分钟,
  这是其在线预算的真实代价,构成"可部署性"结论的一部分);B0–B3 视算力补充跑全 300 集。
  披露:confirm300 复用;⑤仅为有限候选+采样下的近似参照;B1 的 CPU 由**纯计数包装器**测量
  (行为零改动)。
