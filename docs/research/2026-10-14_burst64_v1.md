# Burst64-v1 高竞争工作负载:构造与结构审计(2026-10-14)

> 本轮只做工作负载构造与结构性 Pilot:**未修改预测器/调度算法**;未覆盖 Natural/confirm300;
> 未运行大规模 MILP;未按调度收益挑选 workload 参数。混合全集版本仅用于结构诊断。

## 1. 构造(全部复用现有件)

| 件 | 复用来源 |
|---|---|
| 640 冻结模板 + causal_v3 拓扑 + 资源 profile | `job_templates_r7_v041.jsonl`(sha 入 manifest) |
| Alibaba PAI v2020 到达间隔读取 + 连续片段抽样 | `build_workload_v02._load_arrival_gaps`(train 分片 631,102 个间隔) |
| deadline 预算约定 | 自然约定:`deadline = arrival + (1.5\|2.0\|3.0)[ep%3] × total_p90` |
| 到达变换/配对纪律/一致性检查 | `build_stress_v2_episodes.py` 的"只改到达、保持预算"框架 |

**设计**:640 模板按 **(来源 split × 模型栈 × GPU 成本三分位)** 分层,轮转分配 + 残余重平衡 → 10 集 × 64 个互不重复任务(全集恰好覆盖 640,每模板只用一次);provenance 全保留。
**到达**:每集独立抽一段**连续 63 个 Alibaba 间隔**(不放回);四条件变换 `Δt' = T·Δt^β/ΣΔt^β`,**T = W/(2ρ)**,W = 该集 GPU 工作量(Σ GPU 车道 runtime_p50,与仓库 `total_gpu_runtime` 约定一致)。
**四条件**:(ρ,β) = (0.85,1.0) / (1.10,1.0) / (0.85,1.5) / (1.10,1.5);**β=1.5 为合成 burst enhancement,非生产 trace**。
**配对共享**:成员/身份/间隔片段/GPU 配置/初始驻留(cold)/种子全部一致,仅到达与 deadline 变化;主条件 all-normal 优先级(旧 synthetic priority 留 `--priority-variant` 单独对照)。

## 7. 范围与未验证假设

- 混合全集(480 train + 160 validation 模板)**仅结构诊断**,不可作预测器泛化结论;
- β=1.5 为**合成 burst**,不可冒充生产 trace;β=1.0 条件的间隔形状直接来自 Alibaba 片段;
- Pilot 中因模拟器来源隔离守卫,采用**内存内 split 覆盖**(诊断专用;文件本身保留 provenance);
- 串行环境预取为 0(该维度机会需预取变体另测);
- Headroom 为**状态级**(规划世界口径),episode 级加总收益尚未验证(扩展评估的主判据之一)。
