# 共驻阶段 P3:最小物理辨识实验协议(v1,待顾问批准后才租 GPU)

> 目的:区分三种候选共驻动态——**piecewise(退出后恢复)** / **一次性并发开销(启动成本,退出后恢复)** / **sticky(退出后仍不恢复)**。当前冻结的 11-cell 表只有整请求耗时,无法辨识;本协议用**偏移启动条件**做辨识,且拟合条件与检验条件严格分离。

## 1. 硬件与环境约束(必须与原始测量同条件)

- GPU:RTX 4080 同类别(不得用其他显卡替代);多进程部署(每模型一 worker);
- 模型与精度:Qwen3-VL-8B / Qwen3-4B / Qwen2.5-VL-3B,bf16;
- 输入档位:与 `real_strata_calibration.json` 同 in/out/images;
- 协议:1 次预热 + ≥3 轮,取中位数;同卡独占(无其他负载)。

## 2. 组合(3 个,代表性优先)

| ID | 组合 | 选因 |
|---|---|---|
| P-1 | 4B[planner] + 8B[answer_generation] | 极端不对称(1.5s vs 0.18s),分段/持续差异最大 |
| P-2 | 8B[planner] + 4B[planner] | 双长任务,物理离散度最小(0.4%),动态速率敏感 |
| P-3 | 8B[planner] + 3B[videotool_spatial] | 长+中,覆盖 3B 档 |

## 3. 条件矩阵(核心:偏移启动)

| 条件 | 启动方式 | 目的 |
|---|---|---|
| T0 | **共同启动屏障**(两 worker 自旋等待同一绝对 wall 时刻) | 复现原始整请求成本;用作**拟合**条件 |
| T1 | 长任务开始后 +Xms 短任务加入 | 重叠起点偏移敏感性;**检验**条件 |
| T2 | 长任务中段 +Yms 加入(残余 ≥ 短任务共驻时长) | 残余进度速率;**检验**条件 |
| T3 | 长任务完成后短任务才启动 | 无重叠负对照(应≈各自 solo) |

**预注册偏移(顾问修订 2026-10-16,先按新机器 solo 时长验证重叠关系后固定)**:

| 组合 | T1 短任务加入 | T2 短任务加入 |
|---|---|---|
| P-1 | +100ms | +400ms |
| P-2 | +50ms | +300ms |
| P-3 | +100ms | +400ms |

原 P-2 Y=1000ms 仅作**幸存者身份反转**的额外探索性诊断,不混入主测试。每条件 ≥5 次有效重复;不因个别不利结果反复补采。**实际完成顺序逐轮记录,不得事后筛除反向完成样本。**

## 4. 仪器化(顾问修订:原 wall_start 在前置同步之前,不得当 GPU 开始时间)

1. **统一主机单调时钟**(time.monotonic_ns),每轮至少记录三个时刻:**收到请求/等待屏障** → **前置同步后 generate 开始** → **后置同步后请求结束**;
2. **共同启动屏障**:go 携带目标单调时刻,worker 自旋至该时刻;屏障偏差 >50ms 记为失败样本(fail-fast,不静默丢弃);
3. **实际重叠区间** = [max(gen_start), min(gen_end)] 及双方重叠占比,逐轮记录;
4. **生成进度采样(升为重点)**:每 N token 记录一次单调时刻,直接观察**同伴退出前后幸存任务局部速率**;若仪器化引入明显延迟,必须用**同仪器化条件**测 solo 对照;
5. 原始 JSONL(逐轮)随 artifacts 冻结入库;注明"主机侧窗口重叠 ≠ GPU kernel 并行重叠"的证据边界(如可行加 CUDA event/profiler 佐证)。

## 5. 分析与判据(模型定义事前冻结,拟合/检验分离)

**三个冻结模型**(事后不得修改定义):
- **piecewise**:重叠期各按自身倍率,同伴退出后幸存者恢复速率 1;
- **sticky**:共驻后倍率保持到各自完成,退出不恢复;
- **one-time**:共驻仅加固定一次性开销 c,速率不变。

1. 仅用 **T0** 拟合参数;T1/T2 为独立偏移启动检验;T3 为无重叠负对照(应≈solo);
2. 指标:**逐轮配对误差、误差分布(mean/worst/系统偏差/离散)**;不以"落入三轮 min-max 区间"为唯一判据;
3. 原预注册 **max(3%,30ms) 仅作固定工程参考**,不得事后修改为使某模型通过;
4. 若三模型在 T1/T2 全部失败 → 结论为**模型类别不足**,不自动提容差或强选;
5. 若可获逐段速率:直接比较退出前后速率(最直接判据,优先于终点)。

## 6. 租机条件(四条件全满足才开机计费)与预算

1. **硬件可比**:RTX 4080 类设备、**显存约 32GB**(不得用 16GB 配置——bf16 双模型可能装不下),记录设备名/显存/部署方式;
2. **环境可核查**:CUDA/PyTorch/Transformers 及模型版本记录在案;三个模型权重**提前备好**(不在租机后下载);
3. **Runner 就绪**:CPU 侧协议自测通过(双 worker 屏障/三时间戳/重叠/断言/预算守卫/日志格式,已实现:`scripts/real_strata_colocation_remeasure.py --dry-run`;分析:`scripts/colocation_p3_analysis.py`);
4. **参数冻结**:T0-T3 偏移/重复次数/判据事前固定,不许看结果后改。

预算:一次 **60-90 分钟**上限;前 10-15 分钟环境+双模型共驻+仪器化 smoke;然后 P-1/P-2 主测试,P-3 余量内。环境/加载失败立即停止并提交失败证据;不自动换 GPU 型号。
