# 共驻阶段 P3:最小物理辨识实验协议(v1,待顾问批准后才租 GPU)

> 目的:区分三种候选共驻动态——**piecewise(退出后恢复)** / **一次性并发开销(启动成本,退出后恢复)** / **sticky(退出后仍不恢复)**。当前冻结的 11-cell 表只有整请求耗时,无法辨识;本协议用**偏移启动条件**做辨识,且拟合条件与检验条件严格分离。

## 1. 硬件与环境约束(必须与原始测量同条件)

- GPU:RTX 4080 同类别(不得用其他显卡替代);多进程部署(每模型一 worker);
- 模型与精度:Qwen3-VL-8B / Qwen3-4B / Qwen2.5-VL-3B,bf16;
- 输入档位:与 `real_strata_calibration.json` 同 in/out/images;
- 协议:1 次预热 + ≥3 轮,取中位数;同卡独占(无其他负载)。

## 2. 组合(3 个,代表性优先)

| ID | 组合 | 选因 |
|---|---|---|
| P-1 | 4B[planner] + 8B[answer_generation] | 极端不对称(1.5s vs 0.18s),分段/持续差异最大 |
| P-2 | 8B[planner] + 4B[planner] | 双长任务,物理离散度最小(0.4%),动态速率敏感 |
| P-3 | 8B[planner] + 3B[videotool_spatial] | 长+中,覆盖 3B 档 |

## 3. 条件矩阵(核心:偏移启动)

| 条件 | 启动方式 | 目的 |
|---|---|---|
| T0 | **共同启动屏障**(两 worker 自旋等待同一绝对 wall 时刻) | 复现原始整请求成本;用作**拟合**条件 |
| T1 | 长任务开始后 +Xms 短任务加入 | 重叠起点偏移敏感性;**检验**条件 |
| T2 | 长任务中段 +Yms 加入(残余 ≥ 短任务共驻时长) | 残余进度速率;**检验**条件 |
| T3 | 长任务完成后短任务才启动 | 无重叠负对照(应≈各自 solo) |

每条件 ≥3 轮(建议 5)。X/Y 取值预注册(如 P-1:X=100,Y=400;P-2:X=300,Y=1000)。

## 4. 仪器化(相对原脚本必须新增)

1. **保存 wall_start/wall_end**(worker 已返回,原脚本丢弃)——强制写入原始日志;
2. **共同启动屏障**:go 指令携带目标 wall 时间戳,worker 收到后自旋至该时刻再计 t0;
3. **实际重叠区间** = [max(wall_start), min(wall_end)],逐轮记录;
4. 可选(强烈建议):逐 token/分段进度时间戳(每 N token 记录一次),直接观察**短任务退出前后长任务速率**——比整请求终点更直接;
5. 原始日志(JSONL,逐轮)随 artifacts 冻结入库。

## 5. 分析与判据(拟合/检验分离)

1. 仅用 **T0** 拟合候选模型参数(piecewise/sticky/一次性开销各自的倍率与成本项);
2. 用 **T1/T2/T3** 检验:各模型对长任务终点的预测是否落在检验条件逐轮离散区间内;
3. 判据:
   - piecewise 全中 → 恢复型语义;
   - sticky 全中 → 持续型语义;
   - 仅"一次性开销"模型全中(终点 = solo×slowdown 但**退出前速率不降/或启动段固定损耗**)→ 混合语义;
   - 三者都不能解释 → 记录"当前仪器仍不可辨识",不强行选模型;
4. 若可获逐段速率:直接比较退出前后速率(最直接判据,优先于终点)。

## 6. 预算与门槛

- 预计 <1 小时 GPU 墙钟(3 组合 × 4 条件 × 5 轮 × ~2-5s/轮 + 模型加载);
- **不立即执行**;需顾问批准 + 确认 RTX 4080 可获得性后单独申请;
- 若同硬件短期不可得:共驻阶段冻结为"**物理干扰已测量、动态执行语义未校准**",不采用仅因重现原表而看似正确的模型。
