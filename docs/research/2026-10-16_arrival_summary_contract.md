# 低维到达信息摘要实验契约(v0,待顾问审批)

> 目的:验证**完美到达信息的调度价值能否被"可预测的低维摘要"保留**——决定"预测什么"这一研究问题。依据:顾问 2026-10-16 方向裁定("优先研究未来短窗口到达数量、模型需求直方图、粗粒度到达时间与模型组合")。**本文件仅为契约,审批后才运行。**

## 1. 信息摘要定义(三组,预注册)

| 组 | 摘要内容 | 粒度 |
|---|---|---|
| **S1 到达数量** | 未来短窗口内的任务到达**数量**(不看身份) | 窗口:10s / 30s / 60s 三档 |
| **S2 模型需求直方图** | 未来短窗口内各**模型**被需要的次数(按模板的 GPU 模型集合归并) | 同上三档;模型宇宙=4 个 GPU 模型 |
| **S3 粗时间桶×模型组合** | 到达时间分桶(如 30s 桶)+ 每桶的模型需求组合 | 桶宽:30s |

**非前视约束**:所有摘要只由"当前时刻之后、窗口内"的**真实未来**计算(离线 oracle 口径);不得包含窗口外信息;不得按场景 ID 分组。

## 2. 信息分组与评价契约(防"摘要退化为场景 ID")

- 每个状态内,场景按**摘要取值**分组(相同摘要值的场景归一组);
- **组内**取最优固定动作;期望成本 = 各场景按组决策后的平均;
- 若某摘要的取值把 8 个场景全部分散(即摘要=场景 ID)→ 该摘要视为**不可用**(记录并排除,防止偷回完美信息);
- 同时报告:**摘要组的平均规模**(场景数/组)与**保留率** = VOI(S_i) / VOI(完美)。

## 3. 评价方法

- 复用 Gate 1A 的冻结状态与捐赠场景(不新增 DES 采集:直接使用 gate1a_p2.json 的**完整成本矩阵**进行分组重算——零新增回放);
- 对每个状态、每个摘要:计算 VOI(S_i) 与保留率;分层聚合;
- 报告:各摘要保留率(平均/范围)、组规模、退化排除数、与 Top-K 的交互(可选);
- **独立评价**:如做可行性探索后发现某摘要保留率高,再申请"拟合/评价场景分离"的确认运行(需新场景池,另行审批)。

## 4. 预算与停损

- 本分析**零新增 DES**(纯成本矩阵重算),预计 <10 分钟 CPU;
- 停损:若所有摘要的保留率 <20%(且组规模合理),则判定"完美信息价值难以被低维摘要保留",该方向降级为理论边界,不进入预测器开发。

## 5. 输出

- 摘要保留率表(逐状态 × 三组摘要 × 三档窗口);
- 结论:哪些可预测统计量保留了完美信息价值 → 决定"系统级预测目标"是否存在。
