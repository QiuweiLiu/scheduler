# 主线调度策略参数出处清单(`pdrs_resident` = F0 排序 + 最小 ΣV 驱逐 + 保守预取 + PDRS 折算)

> 目的:科学诚实度审计——回答"策略里有没有拍脑袋决定的参数"。
> 结论:**无拟合超参、无 confirm300 上调参**;可疑项 = 4 个离散设计选择 + 2 个继承约定,全部应披露。

## A. 有证据支撑(非拍脑袋)

| 参数 | 值 | 依据 |
|---|---|---|
| 前瞻视野 H | 5 步 | 预测工件提供 ≤5 步;历史 h1/h3/h5 臂对比中 h5 最优 |
| 未来时长口径 | p95 | Phase 20-B 消费研究:p90≈p95 有效、p50≈均值无效、scaled-p50 显著更差 |
| 动作折算规则 | 存活×分布×软加载 | GPT 第 6 轮推导;实测与 F0 式折算打平(f0point≈pdrs)→ 不敏感 |
| 驱逐子集选择 | 精确枚举最小 ΣV | 无自由参数(模型数少,全枚举) |
| 平局规则 | 先到先得/任务号/卡号/字典序 | 约定,非调参 |

## B. 继承自冻结 F0、本轮未重新验证(应披露)

| 参数 | 值 | 问题与缓解 |
|---|---|---|
| 加载硬阈值 | `p_load ≥ 0.5` 才计加载 | F0 传统规则;实测仅 5.4% 步骤触发,丢掉 94.6% 加载信号。缓解:硬阈值版 vs 软概率版打平 → 效果有上界 |
| 当下成本口径 | runtime_p50 + load_p50 | 与未来项 p95 不一致;继承自 F0 键;未单独消融 |

## C. 设计选择、未做敏感性(最应披露)

| 选择 | 现状 | 未测 |
|---|---|---|
| 预取视野 k=1(只看下一步) | GPT 理由:"预取是短视动作" | k≤2 |
| 每次最多一个预取在途 | 保守 v1 | 并发预取=2 |
| 预取不触发驱逐 | GPT 设计约束 | 预取+驱逐联合 |
| V/U 聚合范围 = ready+running 前沿 | 解释选择 | 只算 running |

## D. 非策略参数

shuffle seed 11、bootstrap seed 11(控制/统计)。

## 建议的敏感性实验(各 ~5-8 分钟,只改一处)

1. 预取 k≤2(把 `nexts` 改为前 2 步求和);
2. 预取并发=2(两张卡各允许一个在途预取);
3. (可选)V/U 只聚合 running 节点。

结果无论正负均可入论文:"这些选择不敏感"或"k/并发有影响"。
