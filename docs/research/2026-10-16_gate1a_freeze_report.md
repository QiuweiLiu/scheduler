# Gate 1A 冻结报告:有限场景池下的完美到达信息价值(2026-10-16)

> 定位:**探索性案例研究**(Exploratory Information-Value Case Study)。结论限定于冻结的有限捐赠场景池与串行执行环境;所有数字为**完美到达信息的上界**,非可部署预测器收益。依据:顾问 P2 审查裁定(2026-10-16)。

## 1. 结论(按证据强度分级)

**主结论(可直接写论文)**:
- 在固定调度前缀、合法首动作集合与 PDRS 后续策略下,**改变未来到达流能够改变最优首动作**;
- 完美到达信息的决策价值**强烈依赖状态**:8 个状态的范围 0 ~ 1,322.1ms(等权平均 ≈546.4ms;仅计 ≥2 动作的 7 状态 ≈624.5ms);
- 该价值需要**两个条件同时成立**:①剩余未来不确定性(未到达任务>0)×②足够多的可竞争候选动作(≈8+)。限制候选至 Top-2/4 时价值降至 ~1/4~1/3(K=8 捕获 93-100%);
- **"选得好"与"知道未来"是两个独立收益来源**(例:ep12@0.55 固定动作提升 872ms / VOI 262ms;ep09@0.35 固定提升 8ms / VOI 660ms)。

**不可声称(明确禁止)**:
- "中等竞争甜点区"为一般规律(样本仅 8 状态/6 episode,ep12 被取样 3 次;动作空间大小与未来任务数混淆);
- 完美信息价值可被实际预测器直接兑现;
- "早期有价值、深队列无价值、后期不适用"作为普遍结论。

## 2. 方法与规模

- 状态:8 个预冻结状态(分层:多未来 45-56 / 中等 21-25 / 少 1-2;来自 train eps 7-14;选择规则=按剩余未来到达数排序取顶 3/中 3/末 2,不按收益挑选);
- 场景:每状态 = 原未来 + 7 个冻结捐赠未来(train eps 4/5/6+15-18;按已到达数量对齐;首个重锚定到达 ≥ t+500ms);
- 动作:全部合法 (node_id, gpu_index);强制首动作 + 固定 PDRS 续跑;同场景共享同一未来;
- 断言(全部通过,硬失败 0):派发时刻一致、动作池一致、场景状态指纹一致、强制动作完整执行(node+gpu)、任务全完成、捐赠到达唯一匹配;
- VOI_arrival = min_a E_ω[ΔJ] − E_ω[min_a ΔJ](等权冻结捐赠);
- 墙钟:重放 2,405s;DES fingerprint(serial_prefetch_v1 config sha)。

## 3. 负结果与排除(如实记录)

- **ep03@0.50 排除主表**:实际派发时刻(863,637.877)四场景状态审计不一致(identical=False),原 148.4ms 降为附录;
- **ep12@0.25 池=1**:无选择空间,VOI 结构性为 0;
- **ep02@0.75(P1)**:任务全到达,到达-VOI 结构性不适用;
- **同状态 VOI 对捐赠集敏感**:ep00@0.60 在捐赠集 {1,2} 下 +285.1ms、{4,5,6} 下 0ms——VOI 不是状态的固定常数;
- **Top-K 限制会显著损失价值**(见 §1)。

## 4. 场景拼接契约的已知限制

- 仅变"未来到达流";在途任务剩余时长固定(确定性 DES);拼接场景为"到达场景敏感性集成",非真实条件未来分布;
- 锚点=已到达数量对齐;捐赠集同来源(train);不含 validation 来源;
- 非前视:分析只用冻结摘要,决策规则不读真值;但本报告的全部 VOI 均为离线完美信息上界。
