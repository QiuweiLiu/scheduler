## 3. execute 轴族多步(三路线对比)

站在 execute 位置 q,预测未来第 k 个 execute 的族:

| k | 直接 XGB | rollout(自回归) | GRU 序列 |
|---|---|---|---|
| 1 | 0.7560 (n=455) | 0.7560 | 0.7280 (n=261) |
| 2 | 0.7557 (n=352) | 0.7472 | 0.7433 |
| 3 | 0.7356 (n=261) | 0.7471 | **0.7778** |
| 4 | 0.7558 (n=172) | 0.7151 | — |
| 5 | 0.7529 (n=85) | 0.7412 | — |
| W=3 全命中 | 0.5402 | 0.5939 | 0.5900 |

发现:
1. **直接多步几乎不随 horizon 衰减**(0.75-0.76 持平)——execute 序列高度周期(6 个 execute 模式重复),族选择与位置相关而非纯时序。
2. **rollout 与直接差距小**,无显著误差累积;W=3 反而更高(小样本波动,如实记录)。
3. **NN 长尾类丢失(2026-08-07 追加,经管线严格验证)**:GRU/BiLSTM/Transformer/CNN/MLP 的 test 预测分布高度趋同([213,48,0,0,0,0] 附近),select_frames+visual_qa 两类之外的类(真实 temporal_ops 55 个 / summarize 4 个)几乎从不被预测——精度 0.728 超 select 先验(0.667)是头部两类内的真实学习,但对调度致命(漏掉 21% 的 temporal_ops 资源需求)。**管线已验证无 bug**:同 seed 两次逐位一致(确定性)、loss 1.83→0.89 正常下降(训练有效)、4 个 seed 的 argmax 差异仅 0-2/783(初始化敏感但收敛到同一决策边界)。"GRU k=3 反超 XGB"结论作废;参数量(14K-83K)与模型族无实质差异,类权重无效。
4. **retest 单步 NN 不受影响(对照验证)**:事件轴单步(562)的 GRU/BiLSTM 预测分布多样化 [403,94,46,19,0,0](select 先验 370),0.8078/0.8096 为真实学习——坍缩是多步弱特征任务的特有现象,不传染单步。

发现:
1. **runtime 多步单调衰减 20.5%→28.3%**——"下一步要多久"可预测性良好。
2. **与生产单步 12.4% 不可比**:生产模型(partA)是"当前行 runtime 回归"(当前行语义,事后回填);多步是"未来第 k 个资源事件"(调度可用口径),任务更难,数字更低是预期的。
3. **peak 近确定性**(1.1%)——peak_allocated_mb 由模型唯一决定,多步等价查表。
4. **load 样本不足**(train <50,k=2+ 无样本),不可用,标注弃用。

## 5. 结论与生产建议

1. **调度接口采用多步预测**:角色(事件轴,k≤3)+ 族(execute 轴)+ runtime(资源轴 k≤3)三层,窗口 W=3。
2. **族预测:直接 XGB(生产)**,W=3 窗口级 0.54 全命中是保守下限,per-step 0.75+ 可用。NN 坍缩,不采用(详见第 3 节修正)。
3. **资源:runtime 多步 k=1..3(20.5%→24.3%)直接接入 score;peak 用模型属性表查表即可**。
4. **load 从生产接口移除**(样本不足)。
5. **口径修正落地**:nn_improvement_plan_20260807.md 对照表 0.8950 → 0.7954(next 语义锚点);"NN 大幅落后树"结论撤销,改为"同量级,GRU 长 horizon 占优"。

## 6. 偏离记录

1. 锚点特征为 script1 近似复刻(ctx + prev_rt/prev2_rt + prev/cur role one-hot),与 script1 的 prev2+cross3 完整特征略异;0.7954 为近似,误差 ±1pp 量级。
2. rollout/GRU W=3 高于直接属小样本波动(n=261),不作结论。
3. GRU 修复两次维度 bug(hist slice 偏移 + 数值列切片),均如实修复重跑。
4. **NN 长尾类丢失(追加)**:nn_ablation_multistep.py + diag_pipeline.py 验证:管线确定性(同 seed 逐位一致)、训练有效(loss 正常下降)、初始化敏感度 0-2/783 决策;所有 NN 收敛到"只预测 select/vqa 两类"的决策边界,长尾类(temporal_ops 等)丢失。已修正第 3 节结论并撤销"GRU 反超"。retest 单步 GRU(0.8096)经分布验证有真实多类学习(temporal 46/94),不受影响。
