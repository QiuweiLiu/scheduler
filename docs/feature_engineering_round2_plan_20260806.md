## 结果

(执行后填写)

### Part A:特征收敛(资源侧 XGBoost,test 1,412 行)

| 组合 | rel MAE | 判定 |
|---|---|---|
| 基线(18 维,参照) | 13.7% | — |
| +prev2 | 14.3% | 单独降,剔除单用 |
| +cross3 | 13.2% | 单独 +0.5pp ✅ |
| +life | 16.2% | 明显降 ❌ |
| +vidhist | 15.2% | 降 ❌ |

**最优特征集 = 基线 + prev2_runtime + 三阶交叉**(资源侧 12.4%,量级分桶 95.7%);life/vidhist 因噪声剔除;事件间隔数据缺口。

### Part B:NN 三形态对比(最优特征集,动作族 Top-1,test)

| 形态 | Top-1 | 结论 |
|---|---|---|
| **XGBoost(最优特征)** | **0.8950** | 全场景最佳(特征增强 +4.5pp vs 0.8505) |
| ③ 级联 NN(角色概率→动作族) | 0.8843 | **NN 三形态最优**——角色概率特征有效 |
| ① 单任务 MLP | 0.8772 | |

| ④ 角色级单任务 MLP | 0.8368 | **未超 XGBoost 角色(0.9151)**——角色级推论不成立 |

### 整体输出评估(行为侧端到端,全量 test 1,520 行,next 语义)

在单级对比之外,补行为侧**整体输出**评估(角色 → execute 触发 → 动作族,统一口径):

| 模型 | join | 执行者路由 | 资源分层 |
|---|---|---|---|
| **XGBoost(级联)** | **0.8493** | **0.9520** | **0.9059** |
| ① 单任务 MLP + 角色 XGB | 0.8289 | 0.8934 | 0.8329 |
| ③ 级联 NN | 0.7612 | 0.8579 | 0.7993 |
| ② 多任务 NN λ=2 | 0.7447 | 0.8533 | 0.8007 |
| (旧特征集架构对比 A 参照) | 0.8355 | 0.8822 | 0.8408 |

**结论(整体视角)**:
1. **整体输出上 XGBoost 全面领先**(join 0.8493 / route 0.9520 / layer 0.9059),优于旧特征集架构对比(+1.4pp join / +7pp route)。
2. **NN 三形态在整体输出上明显落后**(join 0.74-0.83)——单级动作族接近树的结论**不适用于整体管线**;角色级误差经级联放大,NN 的"角色头"是短板。
3. **生产配置最终确定(整体口径)**:行为侧端到端 = **XGBoost 级联**(角色 XGB + 动作族 XGB,最优特征集),join 0.8493 / 执行者路由 0.9520 / 资源分层 0.9059。
4. NN 仅作单级对照记录;不再作为行为侧主选。

### 结论与生产配置

1. **最优特征集**:全关系 + prev2 + cross3——资源侧 12.4%、行为侧 XGBoost 0.8950。
2. **NN 三形态结论**:级联 > 单任务 > 多任务(λ 大时接近单任务);**级联的"角色概率喂动作族"是唯一有架构增益的 NN 形态**,但仍差 XGBoost 1.1pp。
3. **NN 超树的结论被修正**:在"最优特征集"下 XGBoost(0.8950)反超单任务 MLP(0.8772)——此前 0.8630 超 0.8505 是因为树没吃到 prev2/cross3;特征公平后树仍领先。
4. **角色级 NN 不成立**(0.8368 vs 0.9151)。
5. **最终生产配置(冻结)**:
   - 行为:角色 XGBoost 0.9151 → 动作族 XGBoost 0.8950(最优特征集)
   - 资源:XGBoost 12.4%(最优特征集,量级 95.7%)
   - 特征契约:全关系 + prev2 + cross3(两侧统一)
   - NN 记录为候选:级联 0.8843(若未来需要 NN)
6. **下一步**:调度器集成(score 函数 + 20k workload 仿真对比)。
