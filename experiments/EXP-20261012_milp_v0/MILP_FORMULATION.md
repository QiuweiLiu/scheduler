## 3. 集合与参数

`G` 卡;`J` 未完成请求;`R` 就绪 GPU 节点;`V` 预测虚拟节点;`P = R ∪ V`;`C_g` 容量;`base_g = Σ_m ρ01_{g,m}·u_m`;节点 i:`m_i, lane_i, p_i, ℓ_i, w_i`。

**时长口径(M3 修正)**:
- `p_i = max(0.1, runtime_p50_ms − load_p50_ms)`(**纯计算**,扣除可能已含的加载);
- `ℓ_i = load_p50_ms`(仅当 `z_i=1` 时计入);
- 与 DES 对应:`Node.compute_ms` 属性(见契约文档 §2)。

**H5 边界**:`b_j` = 请求 j 链上第 H 个节点(不足则链尾);**CPU-lane 节点同样计入链与边界**(见 §5 CPU 约束)。

## 4. 决策变量(闭合)

| 变量 | 类型 | 含义 |
|---|---|---|
| `x_{i,g}` | {0,1} | GPU 节点 i 分配到 g(CPU 节点无此变量) |
| `s_i, c_i` | 连续 | 计算开始/完成;**`c_i = s_i + p_i`(等式)** |
| `y_{i'ig}` | {0,1} | 对无序对 {i',i} 与每个 g:两者都在 g 且 i' 在 i 前 |
| `ℓ_{im}` | {0,1} | 辅助:模型 m 已被 i 之前的同卡节点使用 |
| `z_i` | {0,1} | i 需要冷加载(首用者且初始未驻留) |
| `q_{i'i}` | {0,1} | 辅助:AND(`z_{i'}`, `y_{i'ig}`)(容量核算用) |
| `e_{g,m}` | {0,1} | **仅 v0b**:驱逐(派生,见 §5-C5) |

## 5. 约束

**(C1) 唯一与因果**
- ∀i∈P: `Σ_g x_{i,g} = 1`(GPU 节点);
- 链式 `s_{i_k} ≥ c_{i_{k-1}}`、`s_{i_1} ≥ c_anchor`;**虚拟节点不可能先于其锚点**,因此首动作必为真实就绪节点(配合 §6)。

**(C2) GPU 条件化互斥与含加载时序(v3 闭合)**
- 对每对 {i',i}、每 g:`y_{i'ig} ≤ x_{i'g}`,`y_{i'ig} ≤ x_{ig}`,`y_{i'ig} + y_{ii'g} ≤ 1`,`y_{i'ig} + y_{ii'g} ≥ x_{i'g} + x_{ig} − 1`;
- **操作起点(含加载)**:`a_i = s_i − Σ_g ℓ_{ig} z_{ig}`(线性:ℓ 为参数、z 为二元);
- **可用与因果**:`a_i ≥ c_{i'}`(链前驱,经 x 激活);`a_i ≥ Σ_g x_{ig}·gpu_available_at[g]`;
- **同卡互斥统一用 [a_i, c_i]**:`a_i ≥ c_{i'} − U(1 − y_{i'ig})`;
- **首动作立即可派发**:最早操作必须 `a = now` 且为真实就绪节点(不允许隐式未来启动;实现为提取规则 + 约束 `min_i a_i = now` 的可验证形式);
- 不同 GPU 无任何先后约束。

**(C3) 冷加载(GPU 条件化,v3 索引修正)**
- **同卡前序模型判定**(v0a,无驱逐):`h_{ig} ≥ y_{kig}`(∀k≠i: m_k=m_i);`h_{ig} ≤ Σ_{k≠i: m_k=m_i} y_{kig}`;
- **GPU 条件化冷加载**:`z_{ig} = AND(x_{ig}, 1−ρ01_{g,m_i}, 1−h_{ig})`:
  `z_{ig} ≤ x_{ig}`;`z_{ig} ≤ 1−ρ01_{g,m_i}`;`z_{ig} ≤ 1−h_{ig}`;`z_{ig} ≥ x_{ig} − ρ01_{g,m_i} − h_{ig}`;
- `z_i = Σ_g z_{ig}`(每节点单卡 → 仍二元);加载时长 `ℓ_{ig} = ℓ_i`(参数),仅经 z 进入时间与容量式;
- **v0a 前提**:无驱逐、加载后持续驻留 → h 判据充分;v0b(重载)需事件级 R/L/E 索引,已暂缓。

**(C4) 容量(事件级计费,v3 修正)**
- 计费集合:初始驻留 `S0_g = {m: ρ01=1}`(**只计一次**)+ 计划加载 `{m: ∃i 分配到 g, z_{ig}=1}`(**每模型一次,不重复计**);
- 对每个执行事件(节点 i 分配到 g,无论加载与否):
  `Σ_{m∈S0_g} u_m + Σ_{m∈L_g(i)} u_m + (w_i − u_{m_i})⁺ ≤ C_g`,
  其中 `L_g(i)` = 在 i 的加载时刻之前已加载的模型集合(由 `q_{i'i}=AND(z_{i'g}, y_{i'ig})` 线性化);
- **缓存命中同样检查 workspace**(`(w_i − u_{m_i})⁺` 项无条件保留);
- **只对对应 GPU 的执行事件激活**(约束经 `x_{ig}` 条件化;v2 的全局激活错误已修);
- v0b:加驱逐项(暂缓)。

**(C5) 驱逐(v0b 派生,非自由决策;M4 修正)**
- `e` 不由优化器自由选择,而是**按 DES 默认规则从计划导出**:对每个加载事件,按 `plan_gpu_admission` 的驱逐偏好/价值(串行配置下=主线 min-V;或动作指定的 largest-first)确定被驱逐集合;
- 约束:①只驱逐非在用模型(执行区间不覆盖该时刻)②转移式一致 `R = base + L − E` ③**若规则导出的驱逐集仍不足准入 → 该状态不可行 → 回退**(与 DES 执行行为天然一致,不再出现"计划驱逐、执行不驱逐"的分裂)。

**(C6) 冻结初始态**:在跑任务/在途加载为参数;任何变量不改写其区间。

**(C7) CPU 节点(M6 新增)**:`lane_i=cpu` 的链节点:无 `x/z/y`,不占 GPU/容量;仅 `s_i ≥ 前驱 c`,`c_i = s_i + p_i`;链与边界照常参与目标。

## 6. 首动作合法集(P0 新增)

- **首动作 = 最早开始的"真实就绪节点"操作**(仅从 R 中选取;并列按冻结 F0 键);
- 模型级约束:`s_v ≥ c_anchor` 已保证虚拟节点不可能成为最早操作;
- **执行前校验**:首动作 ∈ DES 当前合法动作集,**逐个 (node,gpu) 验证**(执行准入 `gpu_can_dispatch_node` + v0a 无驱逐准入),**不得用 `dispatchable_gpus × Ready` 笛卡尔积**(v2 错误已修);
- **无合法动作时**:显式等待(空动作)或回退基线,**不得派发预测节点**(T1 专项)。

## 7. 目标(不变)

`min J0 = Σ_{j∈J} w_j·c_{b_j}`(`w_j=1`;H5 边界完成时间=代理目标;**v0 无终端价值**;不得解释为完整 JCT)。

## 8. Big-M 推导与证明(P1 新增)

```
U = max_g gpu_available_at[g] + Σ_{i∈P}(p_i + ℓ_i) + max_{i∈P}(p_i + ℓ_i)
```

**构造式推导(v3 修正,不再依赖"无空闲"假设)**:
1. 先构造**合法参考调度** R0:F0 顺序、逐卡串行、按需加载、无驱逐(v0a 合法);
2. 取其完成时刻 `U_ref = max_i c_i(R0)` 作为上界来源;`U = U_ref + max_i(p_i+ℓ_i)`(留析取松弛);
3. **显式约束**:∀i `a_i, s_i, c_i ≤ U`(时间变量上界约束直接入模型);
4. 析取失效验证:当 `y=0` 时 `a_i ≥ c_{i'} − U` 右侧 `≤ U − U = 0 ≤ a_i` ✓(因 `a_i ≥ 0` 且 `c_{i'} ≤ U`);
5. 实现时 U 由参考调度在求解前计算(确定性),记录于审计输出。
