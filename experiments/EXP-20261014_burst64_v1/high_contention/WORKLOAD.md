## 1. 构造(复用冻结件,全程可复现)

| 项 | 值 |
|---|---|
| 模板 | 冻结 640 个 VideoSeek 模板(causal_v3 拓扑),**按来源隔离**:train 480 / validation 160 |
| 条件 | **r130_b15**(ρ=1.30, β=1.5)、**r150_b15**(ρ=1.50, β=1.5);β=1.5 为**合成 burst enhancement**(非生产 trace) |

| 到达 | 每集独立连续 63 个 Alibaba 间隔(不放回);`Δt' = T·Δt^β/ΣΔt^β`,T = W/(2ρ),W=集内 GPU 工作量 |
| 配对 | 四要素共享:成员/身份/间隔片段/GPU 配置/初始驻留/种子;deadline 预算逐 job 保持;主条件 all-normal |
| 生成器 | `scripts/build_burst64_v1.py --source {train,validation} --condition-set high` |

**校验(全部通过)**:模板唯一覆盖(480/160)、到达单调、ρ 重算(容差 0.02)、deadline 预算保持、跨条件不变量(身份/预算/片段)、显存合法(最大 19,502 ≤ 32,760)、无真值泄漏。

## 4. 使用纪律

1. **来源隔离**:`train` 来源 = **开发集**(诊断、调参、方法选择);`validation` 来源 = **独立评估集**(正式对比);**不得用评估集做任何选择**;
2. **按条件聚类统计**:两种条件(r130/r150)分开报告,episode 配对;
3. Burst64 **混合全集**(`../` 目录)仍**仅作诊断**,不能用于泛化结论;
4. **不为获得正收益修改本工作负载**;如需新变体(如高模型多样性)→ 新登记版本 + 基线重跑;
5. 环境配置:实验必须声明所用 config(当前默认 `serial_prefetch_v1_extension.json`);F0/PDRS/MILP 同配置重跑。

## 5. 已知局限

- 模型宇宙小(4 个 GPU 模型 ≈ 36GB):显存压力中等、预取/驱逐维度近乎为空(动作域宽度主要来自"派发");
- validation 来源模板池较小(160)→ 动作数略低于 train 来源;
- β=1.5 为合成突发;r150 条件 GPU 饱和(利用率 ~1.0),属"持续过载"场景。
