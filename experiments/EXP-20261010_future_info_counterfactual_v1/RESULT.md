# EXP-20261010_future_info_counterfactual_v1 — 未来信息消除反事实(实验 D)

**问题(预注册)**:主线的驻留动作增益是否依赖"模型切换/驻留压力"结构?
纯 CPU 仿真反事实:全驻留(容量 128GB/卡)与单模型(全部 LLM 节点→8B)。

**设计**(`docs/research/2026-10-10_exp_d_counterfactual.md`):同一 confirm300(id 保留),
α=1.0、容量 32760(参照)/131072(全驻留)/32760+单模型重标;臂 = myopic/F0/主线;
格内 Δ vs F0 + 跨格 Δgain(逐集配对);bootstrap 2000/seed 11;零失败。

## 判据落点与解读

1. **单模型:增益完全消失**。所有 LLM 身份塌缩为一个模型后,主线的驻留动作**无事可做**
   (激活计数全 0,与 F0 逐位相同)——"收益依赖模型切换/身份结构"得到最强形式的支持。
2. **全驻留:增益收缩 73% 但未归零**(−920 → −250,Δgain +670 显著)。驱逐通道归零
   (驱逐=重载=0),残余 −250 全部来自**预取通道**:即使无容量压力,每个(模型,设备)对
   仍有一次"何时装载"的时机问题,预取仍然有效(405 次预取、394 次被用)。
   → 机制分解:**驱逐通道依赖容量压力;预取通道依赖模型切换(无切换即死),但不依赖容量压力**。
3. myopic 在反事实格仍差于 F0(+1130 全驻留)或打平(单模型 −126 n.s.)——排序信息在
   有切换时仍有价值;单模型下排序差异也基本消失。
4. 披露:128GB 为纯反事实上限;单模型重标保留原 runtime/load 记录(上限近似),yolo 保留;
   confirm300 复用;单轮 300 集。
