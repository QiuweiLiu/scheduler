# EXP-20261010_train_prior_isolation_v1 — 训练集先验严格隔离重跑(实验 F)

**问题(预注册)**:实例级未来预测相对**预测器训练集历史先验**是否有独立调度收益?
先验严格只用 j-series `j_train`(拟合 split)构建;先做数据隔离审计;三臂唯一差异 = 预测信息来源。

**设计**(`docs/research/2026-10-10_exp_f_train_prior_isolation.md`,gate 2026-10-10):
reference(F0,无动作)/ Ours(实例包,主线)/ Partial(模型+长度→j_train 先验)/ Full(模型+长度+
运行时+加载+lane→j_train 先验);同一排序规则、同一 GPU 环境、同一驱逐/预取机制;
逐集配对 bootstrap 95% CI(2000/seed 11);零失败;旧实验文件不覆盖。

| 判据 | 实际 |

## 3. 判读(按要求:预测 vs 机制)

1. **收益主体来自调度机制**:即使把模型/长度(Partial)乃至运行时/加载/lane(Full)全部换成训练集
   先验,相同机制仍显著优于 F0(mean −0.46~−0.64s / p95 −2.4~−4.0s)——机制的贡献不依赖实例级预测。
2. **实例级预测的独立增量未获支持**:Ours vs Partial 两主指标均 n.s.;Ours vs Full 在 mean 上显著更好
   (−381)但在 **p95 上显著更差**(+1421)。方向不一致,不构成整体证据。Full 的 p95 优势来自其
   排序通道被通用先验改写(排序退化意外改善尾部);机制未直接观测,**只作事实记录**。
3. **实例信息驱动预取利用方式**:先验臂的预取触发被"聚合 argmax 已驻留"掐灭(333 vs 1,432);
   Ours 的预取量大 4.3×但命中率低(0.419 vs 0.835,配对差显著)——实例身份信息的作用是
   **让预取可执行**,而非提升单次精度。
4. **不得推断"等效"**:H1 的 n.s. 只说明差异小于本设计分辨率;等效需预注册边界 + 等效性检验。

## 4. 披露

- 先验 = 训练集合(240 视频,与工作负载完全不相交)的真实未来目标统计,非预测值;
- Partial 仅替换无排序消费者的字段(排序 byte 一致);Full 的排序变化是设计组成;
- 未替换字段:role/family/retry 等(现无消费者);
- 当前节点估计用工作负载 train_stats,三臂相同;单轮 confirm300;未做等效性检验。
