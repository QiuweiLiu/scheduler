# EXP-20261010_prefetch_value_methods_v1 — 预取模块:高预算 Rollout 蒸馏(B0–B5)

**问题(预注册)**:固定 F0 排序、GPU 环境、驱逐规则与冻结 H5 预测器,只替换预取决策模块;

③这些收益能否由低计算量价值函数保留?

**设计**(`docs/research/2026-10-10_exp_g_prefetch_value_methods.md`;dev 阶段参数冻结):
①B0 无预取(`pdrs_evict`)/ ②B1 主线 U(m)(`pdrs_resident`)/ ③B2 蒸馏价值函数(`pdrs_resident_da`,

Rollout(候选=U(m) 前二+无预取)/ ⑤B5 高预算参照(全部可行(模型,卡)动作 × N*=256 场景);
参照 F0。**评测 = confirm 前 100 集**(预注册:受 B5 在线预算约束),逐集配对 bootstrap 2000/seed 11。

## 2. 三问回答(预注册判据)

1. **主线是否因预取公式浪费未来信息?未获支持。** 更强替代(B2 蒸馏/B5 高预算)在 mean 上均
   **不显著优于** B1(−585 [+220] n.s.;+227 [−267,+667] n.s.);且 B3/B5 显著**伤 p95**(+3.9k/+4.9k)。
   连 B1 自身的 mean/p95 相对 B0 也只是不显著的 −99/−303(仅冷加载显著 −1.75/集)。
   → 现行 U(m) 已在本工作负载的可用信息水平附近;瓶颈不在预取公式。
2. **高预算 Rollout 的额外收益 ≈ 0(且为负向),代价极高**:B5−B1 mean +227 n.s.、p95 **+4855 显著更差**,
   决策 CPU **134 ms/次调用(64.6 s/集)**。在"有限候选 × 256 场景 × 有界短程仿真"的近似参照口径下,
   更多计算没有换来完成时间收益。(仅冷加载再降 −2.0/集。)
3. **低计算量价值函数未能保留收益**:B2 是全场最优点估计(mean 68,232、净收益 −36.5 为全臂最优、
   冷加载最低 21.76),但相对 B1 **不显著**(−585 [−1424,+220]);且其拟合本身很弱(val 一致率 0.417)
   ——"蒸馏可行性"未获支持;唯一稳健结论是:预取决策的"更聪明公式"没有可测收益空间。
- 注:三问共同的背景事实 = **预取动作本身的边际收益在此负载上很小**(B1−B0 mean/p95 n.s.),
  与第 6 轮"预取增量 −264 n.s."一致;动作价值几乎全部来自**驱逐通道**(对照:B2 相对无动作 F0
  −1126 显著,冷加载 −8.7)。

## 3. 披露与边界

- confirm300 复用(本次前 100 集为预注册子集,CPU 成本原因);最终仍需独立评估集;
- ⑤只能称"**有限候选 + 采样场景 + 有界短程仿真下的近似最优参照**,不宣全局最优";
- 场景假设:独立边际采样、时长=预测均值、不含未来到达;rollout 模型有界(最早开工派发/串行加载/轻量驱逐);
- β/N* 均在 dev 冻结后未改动;B1 CPU 由纯计数包装器测量(行为零改动);净收益记账约定 1 ms CPU=1 ms。
