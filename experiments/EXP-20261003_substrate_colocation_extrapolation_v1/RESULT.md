# RESULT — EXP-20261003_substrate_colocation_extrapolation_v1（步3：F1 共置外推）

**状态**：完成（2026-10-03）。**远端脚本 `f1_extend.py`；产物 `artifacts/f1_extend.json`。**

## 目的

验证 M3 共置模型（`coloc = solo + 1.387×min(a,b)`）在现有 45 格（short/medium/long）
之外的**外推**：XL 长任务、极端不对称（XS×XL）、错峰加入（staggered）。

## 形状（结构口径）

- XL：纯文字 4096 tok 输入 / 512 输出（solo ≈ 12–16s）
- XS：纯文字 64 tok 输入 / 4 输出（solo ≈ 0.12–0.16s）

## 协议

2 warmup + 3 paired rounds（交替 solo 顺序 + 同时起跑）；中位数；每格约 5.6 min。

## 结果

| 格子 | solo A/B (ms) | slowdown A/B | M3 预测 A/B | 误差 |
|---|---|---|---|---|
| 8B×8B XL×XL | 15940 / 15719 | 2.300 / 2.336 | 2.368 / 2.387 | **−2.9% / −2.1%** |
| 4B×4B XL×XL | 15371 / 15162 | 2.288 / 2.319 | 2.368 / 2.387 | **−3.4% / −2.9%** |
| 3B×3B XL×XL | 11920 / 11906 | 2.342 / 2.343 | 2.385 / 2.387 | **−1.8% / −1.8%** |
| 8B[XS]×3B[XL] | 160 / 12360 | **3.160** / 1.046 | 2.387 / 1.018 | **+32.4%** / +2.7% |
| staggered 8B[XL]→3B[XL]@50% | 15949 / 12010 | A端 26660 / B端 30728 | 27009 / 31045 | **−1.3% / −1.0%** |

## 结论

1. **M3 对 XL 长任务外推成立**：三个自对误差 −1.8%~−3.4%（轻微高估）。
2. **M3 对极端不对称的"小任务侧"失效**：160ms 的 8B 小任务实测被拖慢 **3.16×**
   （M3 预测 2.387，低估 32%）→ 小任务在大任务旁受害更重，**共置决策不应让微小任务与大任务同卡**（或需加下界保护）。
3. **staggered（错峰加入）的剩余工作积分正确**：误差 −1.0%~−1.3% → DES 的"中途加入用剩余工作量"机制有实测支撑。
4. 8B×8B 可行（21.3GB 峰值），推翻此前"不可行"判断（那是两实例假设）。

## 边界

- XL=4096/512 为结构定义；solo 12–16s；不代表任意更长任务。
- 3 paired rounds（screening 级）；单卡共享环境，用中位数。
- XS 格的副本 copy 变体也观察到 2.6–3.5× slowdown（含装载副本）。

## 对仿真器/论文的含义

- M3 的适用域扩展至 XL（自对、错峰）；**XS 极端不对称需例外条款**（或对 min(a,b) 设下限）。
- 8B×8B 共置可纳入可行域。
