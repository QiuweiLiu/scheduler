## 结论（P1 的核心证据）

1. **收益真实且几乎饱和**：p90 ≈ p95 ≫ E0，而 **oracle-truth 只比 p95 好 1.3 s** → 在同一消费形状下，
   该信息已接近用尽。
2. **收益不来自"有未来信息"**：E2 只比 E0 好 0.68 s；**p50 消费与无未来不可分**。
3. **收益来自"保守 + 与具体未来步对齐"的聚合**：
   - **打乱尾部对齐**（tail-shuffle）把收益全部抹掉（相对 p95 +4.25 s，回到 E2/p50 水平）→ 对齐是关键；
   - **放大尺度但不换统计量**（scaled-p50）显著更差（相对 p95 +15.1 s）→ 不是"未来项越大越好"。
4. 与 Phase 18 的新指标一致：p90 求和 ≈ 真实工作量的 95 分位（比值 1.010），p95 为 1.41 倍；
   而"尾部间隙是否标记难度"**不成立**（Spearman = −0.088）→ 收益机制应表述为
   **保守聚合补偿系统性预测乐观并改善排序鲁棒性**，而不是"不确定性信号"或"执行时相关性"。

## 对论文的含义

可写的强主张：**"预测本身收益有限；关键在于把不完美的未来估计转成稳健的决策成本；
一个简单的、与未来步对齐的保守尾部聚合就能接近同形状下的 oracle 上界。"**
