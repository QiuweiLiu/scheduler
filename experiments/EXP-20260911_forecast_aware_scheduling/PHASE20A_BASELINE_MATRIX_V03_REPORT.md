## 结论（相对 100 集冒烟的精化）

1. **冒烟方向成立，但一处需要更精确**：100 集冒烟显示 `E2−E0` 变成 +263（CI 跨 0），
   1000 集显示 **−793 ms，CI [−1,062, −507]（仍显著）**。
   → 正确表述不是"E2 的优势消失"，而是 **"E2 相对 E0 的优势缩小约 97%（27.5 s → 0.79 s）"**。
2. **r95 仍是最优，且 r95−E2 仍显著**（−7.2 s → −4.1 s）→ **"保守尾部消费优于点消费"存活**。
3. **r95 相对 E0 的收益缩小约 86%**（34.7 s → 4.9 s）→ 旧的"未来感知收益"绝大部分是构造放大。
4. **FCFS 的相对位置崩了**（与 E0 持平 → 差 28.0 s）→ 那个 54 秒容器节点此前主导队列动态。
5. 对论文：保留"q95 > p50 / aggregation matters"；删除"未来信息本身有价值（幅度上几乎为零）"与
   "收益随 contention 增强"（后者需在 v03 上重跑 sweep 才能定性）。
