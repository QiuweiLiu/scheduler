# 真实轨迹的公共慢化因子 / 尾部共动检验（T1–T3，2026-09-16）

目的：由于仿真执行真值是固定实测值（无重复执行随机性），"各步是否一起变慢"这一机制假设只能在**真实轨迹**上检验。
数据：640 runs（160 视频 × 2 stack × 2 baseline）、8,663 个成功步、5 个模型类型（按 model_id 分组）。
推断：按 160 个 video 的聚类 bootstrap（B=400/200）+ 分层置换零假设（300 次）；预处理与代码经合成数据验证。

## 结论（三句话）

1. **"各步存在公共慢化因子"被否定**：run 层 ICC ≈ 0，直接测得的**运行内平均协方差为负**（−0.122，111,592 对）。
2. **跨类型残差相关整体为负**（−0.18 ~ −0.26），且在控制序列位置、仅看"后续出现"、不同 min_cell 下都保持负号。
3. **尾部共动为负**（PIT 归一化后按对计算 lift：q=0.8 → 0.93、q=0.9 → 0.70、q=0.95 → 0.31），远低于独立假设的 1。

→ 因此**放弃"真实 runtime 共单调/公共慢化"作为机制解释**（仿真本来也没有重复执行随机性）。

## T1 结果（方差分解）

| 估计量 | σ_video² | σ_run² | σ_eps² | ICC_video | ICC_run |
|---|---|---|---|---|---|
| 矩估计（残差上；未截断） | 0.0017 | **−0.1392** | 2.198 | 0.0008 | **0** |
| MixedLM（re_formula=1, REML） | 0.870 | 0.006 | 2.062 | 0.296 | 0.002 |

- run 均值残差方差 = **0.0377**，纯噪声预期 = σ²_eps/n̄ = **0.1756** → 观测显著更小 ⇒ 负组内相关。
- **直接诊断：运行内平均协方差 = −0.1222**（111,592 对）。
- MixedLM 未收敛（converged=False）且与矩估计差异大；矩估计在合成数据上以已知真值验证准确（0.155/0.293 vs 0.138/0.310），
  故以矩估计 + 直接协方差诊断为主结论，MixedLM 仅作参考并标注收敛问题。

## T2 结果（残差共动，pooled Spearman）

| 变体 | pooled Spearman |
|---|---|
| A 总关联（去 type/stack/baseline） | **−0.242** |
| B 条件于视频（再按 video 去均值） | −0.212 |
| C 位置调整（type×stack×baseline + 位置/长度项） | −0.176 |
| D3 仅"后续出现"（去 warm/cache 组成影响） | −0.261 |
| D2 计数–成本耦合（count vs 单元均值） | Pearson **−0.173**、Spearman **−0.256** |

最极端的对：Qwen3-VL-8B × cpu-metadata = −0.598（min_cell=1），控制位置 → −0.69（min_cell=3）。
- 位置调整只解释了一部分（−0.242 → −0.176）；
- 计数–成本耦合显著为负（调用越多、单步越"便宜"，符合 warm/cache 组成效应）；
- 因此**不能把负号解释成"物理替代/补偿"**，更可能是组成效应 + 位置效应 + 测量噪声的混合。

## T3 结果（尾部共动，PIT 归一化 + 对内 lift）

| q | pooled lift（min_cell=1） |
|---|---|
| 0.8 | **0.93** |
| 0.9 | **0.70** |
| 0.95 | **0.31** |

（lift = P(A∩B)/(P(A)P(B))，对内在 common 子集计算；低于 1 = 负的尾部共动。）

## 边界与后续

- 结论仅适用于本 workload（VideoMME 视频 Agent 轨迹，5 个模型类型）与 model_id 分组；未做 raw_action/GPU-子集 的完整敏感性（可补）。
- 负相关的成因尚未定案（组成/位置/计数-成本耦合；GPT 建议再控制 count 与 warm 后再谈"替代"）。
- **按 GPT 的判定准则（ICC≈0 + 跨类型负相关 + lift≤1）：正式放弃共单调机制叙事**，主解释改为
  **"r95 是对冲预测误差的排序代理（forecast-error-aware ranking surrogate），而不是随机执行风险的估计器"**；
  下一步做三个替代机制检验：① tail-gap 预测预测误差；② 排序 margin；③ 隐式重要性加权。
