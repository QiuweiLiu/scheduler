# Forecast-aware — Phase 10 预测质量敏感性（1,000 episodes，2026-09-15）

目的：回应审稿质疑"q95 是否只是某个 checkpoint 偶然命中调度器"。
方法：对**冻结**的 J3:seed11 artifacts 做三类后处理扰动（只推理、不重训），
在相同 workload/调度器下重跑 q95 消费臂，与未扰动基线配对比较（B=2000，seed 20260915）。

扰动工具：`scripts/perturb_future_artifacts.py`（每行确定性、记录 `perturbation.json`）。
运行：`outputs/phase10_run_*`（8 臂 × 1,000 集；基线 = `outputs/phase9_baselines_1000` 的 q95，180,362ms）。

## 结果（vs 未扰动 q95，配对）

| 扰动 | 强度 | completion Δ (ms) | miss Δ (pp) |
|---|---|---|---|
| **runtime 尾部收缩向 p50**（α 保留比例） | 0.75 | **+4,184 [+3,709, +4,689]** | +0.28 |
| | 0.50 | **+13,431 [+12,101, +14,765]** | +0.96 |
| | 0.25 | **+31,611 [+28,958, +34,506]** | +3.31 |
| **链长噪声**（±1 步，触发概率 ε） | 0.10 | +835 [+636, +1,028] | −0.04 |
| | 0.25 | +3,102 [+2,677, +3,562] | +0.17 |
| | 0.50 | +5,311 [+4,711, +5,889] | +0.29 |
| **内容破坏**（lane gpu↔cpu 翻转概率 ε） | 0.10 | +57 [−0, +119] | −0.02 |
| | 0.50 | +12 [−78, +95] | +0.01 |

## 结论

1. **runtime 尾部是最承重的信号**：把 p95 向 p50 收缩即出现强剂量-反应（保留 75% → +4.2s；50% → +13.4s；25% → +31.6s），
   全部 CI 不含 0。这直接支持 C2：**收益由尾部形状承载，而非某个模型的偶然输出**。
2. **链长信息次之**：±1 步噪声呈弱但有意义的剂量-反应（+0.8s/+3.1s/+5.3s），说明长度/终止结构确有贡献但斜率远小于尾部。
3. **内容（属性/lane）无贡献**：破坏 50% 的 lane 标注对结果无可测影响（+12ms，CI 跨 0），
   与 Phase 4（真值内容更差、去掉身份更好）和 Phase 7C（rt95 ≡ q95）一致。

## 边界

- 扰动是"人工破坏预测质量"的方向性实验，不等于真实域外退化（S_* 审计给出的是另一类证据：role 0.912/family 0.803/pinball 1,045）。
- 仍为单 workload、单预测器、仿真；扰动强度是人为刻度，论文中应说明其构造方式。
- 产物：`outputs/phase10_artifacts_*/`（扰动 artifacts）、`outputs/phase10_run_*/`（运行）、脚本 `.scratch/phase10_stats.py`。
